# CodersPlace - Interview Preparation Platform

A comprehensive interview preparation platform built for students and professionals to master coding interviews, aptitude tests, and technical assessments.

## Features

- **Coding Practice**: DSA problems with easy, medium, and hard difficulty levels
- **ARV Section**: Aptitude, Reasoning, and Verbal ability tests
- **Interview Preparation**: OS, Database, System Design, and Programming Language questions
- **Hackathons**: Coding competitions and contest information
- **Progress Tracking**: Monitor your preparation journey

## Tech Stack

- **Frontend**: React, TypeScript, Tailwind CSS
- **Build Tool**: Vite
- **UI Components**: shadcn/ui
- **Routing**: React Router DOM
- **State Management**: TanStack Query

## Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone <your-repo-url>
cd codersplace
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open your browser and navigate to `http://localhost:5173`

## Available Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run preview` - Preview production build
- `npm run lint` - Run ESLint
